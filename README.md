## The bio

> Single because I kept auto-completing my ex's sentences. In my defense, I was right.

84 characters, one line.

## How it works

`main.py` (pure Python standard library, no dependencies) writes the bio to
`/output/entry.txt`. Run it with:

```sh
python3 main.py
```
